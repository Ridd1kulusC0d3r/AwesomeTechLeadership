# Como contribuir

Leia o [Código de conduta](code-of-conduct.md).

Uma contribuição deve ajudar alguém a tomar uma decisão de liderança. Informe público, problema, ação prática, limitações e fontes.

## Formatos aceitos

- Guia curto com exemplo e exercício.
- Modelo copiável.
- Cenário fictício com alternativas e discussão.
- Referência oficial comentada, com data de consulta.

## Revisão

Use links relativos internos. Verifique afirmações factuais. Não apresente experiência pessoal como regra universal. Não envie dados identificáveis de colegas ou empresas. Não classifique cursos como gratuitos sem verificar as condições.

Abra um PR com o problema resolvido e a verificação realizada.
